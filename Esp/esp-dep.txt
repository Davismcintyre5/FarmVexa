3. WIRING DIAGRAM
================================================================================

3.1 DHT22 — Temperature & Humidity
────────────────────────────────────
    DHT22          ESP32
    ─────          ─────
    VCC (Red)  →   3.3V
    DATA (Yellow)→  GPIO4
    GND (Black)→   GND

    Note: DHT22 needs no resistor (built-in)


3.2 Capacitive Soil Moisture Sensor
─────────────────────────────────────
    Sensor         ESP32
    ──────         ─────
    VCC (Red)  →   3.3V
    GND (Black)→   GND
    AOUT (Blue)→   GPIO34 (Analog)

    Note: Use CAPACITIVE sensor (v1.2) — not resistive.
          Resistive sensors corrode in soil.


3.3 LDR Light Sensor (Voltage Divider)
────────────────────────────────────────
    Circuit:
    3.3V ──→ LDR ──→ GPIO35 ──→ 10k Resistor ──→ GND

    LDR has 2 legs:
    - Leg 1 → 3.3V
    - Leg 2 → GPIO35 + 10k Resistor → GND

    The resistor creates a voltage divider.
    Bright light = high voltage, Dark = low voltage.


3.4 Rain Sensor (Optional)
────────────────────────────
    Sensor         ESP32
    ──────         ─────
    VCC (Red)  →   3.3V
    GND (Black)→   GND
    AOUT (Blue)→   GPIO32 (Analog)

    Note: Place sensor flat in open area.
          Dry = high value, Wet = low value.

5. POWER OPTIONS
================================================================================

Option 1: USB Power Bank (Demo/Testing)
   ESP32 USB Port → Power Bank
   Portable, lasts 8-24 hours depending on bank capacity.

Option 2: USB Wall Adapter (Indoor)
   ESP32 USB Port → 5V USB Adapter → Wall Socket
   Continuous power, no battery limits.

Option 3: Solar + Battery (Field Deployment)
   Solar Panel (5V, 3W) → TP4056 Charge Controller
        → 18650 Li-ion Battery (3.7V, 3000mAh)
        → ESP32 5V Pin

   Parts:
   - 5V Solar Panel:    KSh 300-500
   - TP4056 Module:     KSh 100-200
   - 18650 Battery:     KSh 300-500
   - Battery Holder:    KSh 50-100

   Total Solar Kit: KSh 750-1,300

6. SOFTWARE SETUP
================================================================================

6.1 Install Arduino IDE
    Download: https://www.arduino.cc/en/software

6.2 Add ESP32 Board Support
    File → Preferences → Additional Boards Manager URLs:
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
    
    Tools → Board → Boards Manager → Search "ESP32" → Install

6.3 Install Required Libraries
    Tools → Manage Libraries → Search & Install:
    - "DHT sensor library" by Adafruit
    - "Adafruit Unified Sensor" by Adafruit

6.4 Configure the Code
    Open sensor_node.ino and edit:
    - ssid: Your WiFi name
    - password: Your WiFi password
    - serverUrl: Your MERN server IP + port
    - apiKey: farmvexa_shared_secret_key_here
    - deviceId: Unique name for this ESP32

6.5 Upload Code
    - Connect ESP32 via USB cable
    - Tools → Board → ESP32 Dev Module
    - Tools → Port → COMx (Windows) or /dev/cu.usbserial (Mac)
    - Click Upload (→ arrow)

6.6 Verify
    Open Serial Monitor (Tools → Serial Monitor, baud 115200)
    Should see:
    ✅ WiFi Connected
    📡 Sending sensor data...
    ✅ Data sent successfully

7. REGISTER DEVICE IN FARMVEXA
================================================================================

After flashing, register the device in the FarmVexa dashboard:

    Farmer Dashboard → Devices → Register Device
    Enter Device ID: ESP32_FIELD_01
    Select Farm → Select Field
    Click Register

Or via API:
    curl -X POST http://localhost:5000/api/farm/devices/farm/FARM_ID \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer FARMER_TOKEN" \
      -d '{"deviceId":"ESP32_FIELD_01"}'

================================================================================
9. TROUBLESHOOTING
================================================================================

Problem: ESP32 won't connect to WiFi
    - Check SSID and password (case-sensitive)
    - ESP32 only supports 2.4GHz WiFi, not 5GHz
    - Move closer to router for testing
    - Check router allows new devices

Problem: Sensor returns 0 or NaN
    - Check wiring connections
    - DHT22: Wait 2 seconds between readings
    - Soil: Make sure it's in moist soil
    - LDR: Check resistor value (10k ohm)

Problem: Server returns 404/401
    - Check serverUrl (must include /api/internal/sensors/ingest)
    - Check apiKey matches .env INTERNAL_API_KEY
    - Check deviceId is registered in the system

Problem: Serial Monitor shows gibberish
    - Check baud rate is 115200
    - Tools → Serial Monitor → 115200 baud

      -H "Content-Type: application/json" \

    curl http://localhost:5000/api/farm/sensors/field/FIELD_ID \
