1. ABSTRACT

FarmVexa is a comprehensive AI-powered farm intelligence platform that combines Internet of Things (IoT) sensor data, computer vision for crop disease detection, artificial intelligence for predictive analytics, and a full-featured farm management system into a single unified platform. Unlike traditional farm record-keeping tools that passively store information, FarmVexa actively interprets farm data through multiple AI engines (Google Gemini, HDM AI, and local TensorFlow models) to provide real-time, contextual recommendations.

The software is built using a modern polyglot architecture: Node.js with Express for the MERN backend (MongoDB, Express, React, Node.js), Python with FastAPI for the dedicated AI engine, React with Vite and Tailwind CSS for both the farmer dashboard and admin panel, and C++ for ESP32 IoT sensor nodes. The system supports Redis for caching, Cloudinary for image storage, HDM Bridge for email, Brevo for SMS, and OpenWeatherMap/WeatherAPI/Open-Meteo for weather data.

FarmVexa is accessible as a Progressive Web Application (PWA) via web browser, as a Windows desktop application, as a macOS application, as a Linux application, and as an Android application (APK). The landing page is at https://farmvexa.pxxl.click, the farmer dashboard at /dashboard, and the admin panel at a separate deployment.

The system serves small-scale farmers, medium-scale farmers, commercial farms, and agricultural cooperatives with role-based access control supporting Farmers, Managers, Workers, and Veterinarians. The platform supports both English and Kiswahili languages in its AI chat assistant.

2. INTRODUCTION

2.1 Problem Statement

Farmers often discover crop and farm problems after significant damage has already occurred. Late detection of crop diseases, inadequate or excessive irrigation, limited knowledge of soil conditions, difficulty continuously monitoring farm conditions, and lack of historical farm data for decision-making are persistent challenges. Traditional farming methods depend heavily on visual inspection and experience — valuable but unable to provide continuous, data-driven monitoring.

2.2 Solution Overview

FarmVexa addresses this gap by integrating IoT sensors, computer vision, and artificial intelligence directly into farm operations. The core principle is: See (camera and computer vision), Sense (IoT sensors), Predict (AI and data analysis), Grow (better and earlier farm decisions). The system does not merely record that soil moisture is 15%; it detects declining trends, cross-references with temperature and humidity, correlates with crop image analysis, and alerts the farmer with specific recommended actions.

3.3 Data Isolation Architecture

FarmVexa implements strict data isolation between farms. Every database document contains a farm field referencing the parent farm. Middleware (ownsFarm, ownsField) extracts the authenticated user's ID from JWT and verifies farm ownership before any query executes. Team members are restricted to their assigned farm via TeamMember.farm reference. Cross-farm data access is impossible at the architectural level.

3.5 AI Decision Architecture

The Python AI Engine serves as the intelligence hub with three AI provider options configured via environment variable:

localN/ATensorFlow .h5 modelRule engine (JSON config)
geminiGemini 3.5 FlashGemini 3.5 Flash (always)Rule engine

Crop images always use Gemini regardless of chat AI provider because HDM AI does not support image analysis. Sensor data always uses the local rule engine for speed and reliability. The public chatbot has its own independent AI provider configuration in admin settings.

  const response = await axios.post(`${this.baseUrl}/api/chat`,
    { message, systemPrompt, history: [] },
    { headers: { 'Content-Type': 'application/json', 'x-api-key': this.apiKey }});

}

5.2 Farm Context Injection for AI

Before sending any chat message to AI, the system gathers comprehensive farm context.

// aiContextService.js — builds complete farm context
async getFarmContext(farmId) {
  const [animals, todayProd, stock, alerts, devices, weather] = await Promise.all([
    Animal.find({ farm: farmId, status: 'active' }),
    ProductionRecord.find({ farm: farmId, date: { $gte: today } }),
    Stock.find({ farm: farmId }),
    Alert.find({ farm: farmId, isRead: false, severity: { $in: ['high','critical'] } }),
    Device.find({ farm: farmId }),
    weatherService.getFarmWeather(farmId)
  ]);
  return { farmName, location, animals: { total, byType }, productionToday: { milk, eggs },
    stock: stockSummary, alerts: alertSummary, devices: { total, online }, weather };
}

5.6 Weather Geocoding from Farm Location

// weatherService.js — geocodes farm county/sub-county to coordinates
async getCoordinates(farm) {
  if (farm.location?.coordinates?.lat) return farm.location.coordinates;
  const query = [farm.location?.county, farm.location?.subCounty, 'Kenya'].filter(Boolean).join(', ');
  const res = await axios.get('https://nominatim.openstreetmap.org/search',
    { params: { q: query, format: 'json', limit: 1 } });
  return { lat: parseFloat(res.data[0].lat), lon: parseFloat(res.data[0].lon) };
}

6. CONCLUSION

FarmVexa represents a significant advancement in agricultural technology by combining IoT sensor networks, computer vision for crop disease detection, and multiple artificial intelligence engines into a single unified platform. The system's core innovation lies in its sensor fusion approach — combining camera analysis, environmental sensor data, historical trends, and AI interpretation to provide contextual, actionable recommendations rather than raw data displays.

The platform's multi-provider AI architecture allows deployment flexibility — organizations can use Google Gemini, HDM AI, or local TensorFlow models depending on connectivity, cost, and privacy requirements. The role-based access control system enables farms to onboard workers, veterinarians, and managers with granular permissions appropriate to each role.

The system's 7 automated schedulers (daily briefing, reminders, sensor checks, alert processing, device health monitoring, data cleanup, and vaccination scheduling) ensure proactive farm monitoring without requiring constant farmer attention. The integration of M-Pesa payment processing, printable receipts, and comprehensive financial tracking makes FarmVexa a complete farm business management solution.

FarmVexa's architecture — with 78 MERN server files, 21 Python AI files, 26 farmer dashboard pages, 19 API route files, 10 farm operation modules, 30 email templates, 14 SMS templates, 9 report types, and ESP32 IoT firmware — represents a substantial original work of software development.
