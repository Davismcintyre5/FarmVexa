1. ABSTRACT

FarmVexa is a comprehensive AI-powered farm intelligence platform that combines Internet of Things (IoT) sensor data, computer vision for crop disease detection, artificial intelligence for predictive analytics, live camera streaming for field scanning, storage pest detection, and a full-featured farm management system into a single unified platform. Unlike traditional farm record-keeping tools that passively store information, FarmVexa actively interprets farm data through multiple AI engines to provide real-time, contextual recommendations.

The software is built using a modern polyglot architecture: Node.js with Express for the MERN backend (MongoDB, Express, React, Node.js), Python with FastAPI for the dedicated AI engine, React with Vite and Tailwind CSS for both the farmer dashboard and admin panel, C++ for ESP32 IoT sensor nodes, and hdmstream for live camera streaming and field scanning. The system supports Redis for caching, Cloudinary for image storage, HDM Bridge for email, Brevo for SMS, and OpenWeatherMap/WeatherAPI/Open-Meteo for weather data.

FarmVexa is accessible as a Progressive Web Application (PWA) via web browser, as a Windows desktop application, as a macOS application, as a Linux application, and as an Android application (APK). The landing page is at https://farmvexa.pxxl.click, the farmer dashboard at /dashboard, and the admin panel at a separate deployment.

The system serves small-scale farmers, medium-scale farmers, commercial farms, and agricultural cooperatives with role-based access control supporting Farmers, Managers, Workers, and Veterinarians. The platform supports both English and Kiswahili languages in its AI chat assistant.

2. INTRODUCTION

2.1 Problem Statement

Farmers often discover crop and farm problems after significant damage has already occurred. Late detection of crop diseases, inadequate or excessive irrigation, limited knowledge of soil conditions, difficulty continuously monitoring farm conditions, pest infestations in storage, and lack of historical farm data for decision-making are persistent challenges. Traditional farming methods depend heavily on visual inspection and experience — valuable but unable to provide continuous, data-driven monitoring.

2.2 Solution Overview

FarmVexa addresses this gap by integrating IoT sensors, computer vision, artificial intelligence, live camera streaming, and storage monitoring directly into farm operations. The core principle is: See (camera and computer vision), Sense (IoT sensors), Predict (AI and data analysis), Grow (better and earlier farm decisions). The system does not merely record that soil moisture is 15%; it detects declining trends, cross-references with temperature and humidity, correlates with crop image analysis, scans entire fields with GPS-tagged photos, monitors storage conditions for pest risk, and alerts the farmer with specific recommended actions.

3.3 Field Scan Architecture

The Field Scan module enables full-field crop analysis through live camera streaming with GPS-tagged photo capture. The flow is:

  1. Farmer selects farm, field, and crop type in FarmVexa
  2. Opens External Camera (hdmstream /in embedded in FarmVexa)
  3. hdmstream /out (camera device) starts Field Scan mode
  4. GPS tracking starts on the camera device
  5. Photos auto-capture at configured intervals (default 5 seconds)
  6. Each photo uploaded to Cloudinary with GPS coordinates
  7. On stop, all photos sent to FarmVexa as a batch via postMessage/IPC
  8. Python AI pre-filters frames with OpenCV (blur detection, green coverage, disease indicators)
  9. Top 60% suspicious frames selected and batched (16 per request)
  10. AI analyzes each batch for disease, weeds, pests, and health score
  11. Results returned with GPS locations for field mapping

3.5 Data Isolation Architecture

FarmVexa implements strict data isolation between farms. Every database document contains a farm field referencing the parent farm. Middleware (ownsFarm, ownsField) extracts the authenticated user's ID from JWT and verifies farm ownership before any query executes. Team members are restricted to their assigned farm via TeamMember.farm reference. Cross-farm data access is impossible at the architectural level.

  if (window.electronAPI?.sendMessage) {
    window.electronAPI.sendMessage(data);
    return true;
  }
  if (window.parent !== window) {
    window.parent.postMessage(data, '*');

6. CONCLUSION

FarmVexa represents a significant advancement in agricultural technology by combining IoT sensor networks, computer vision for crop disease detection, live camera streaming for field scanning, storage pest detection, and multiple artificial intelligence engines into a single unified platform. The system's core innovation lies in its sensor fusion approach — combining camera analysis, environmental sensor data, GPS-tagged field scanning, storage monitoring, historical trends, and AI interpretation to provide contextual, actionable recommendations rather than raw data displays.

The field scan module enables farmers to analyze entire fields systematically with GPS-tagged photos, batch AI processing with OpenCV pre-filtering, and automated disease/weed/pest detection. The storage monitoring module provides affordable pest detection using CO2 sensors for insect respiration and PIR sensors for rat movement. The hdmstream integration enables live camera streaming with automatic photo capture and direct sending to FarmVexa.

The platform's multi-provider AI architecture allows deployment flexibility — organizations can use Google Gemini, HDM AI, or local TensorFlow models depending on connectivity, cost, and privacy requirements. The role-based access control system enables farms to onboard workers, veterinarians, and managers with granular permissions appropriate to each role.

FarmVexa's architecture — with MERN server, Python AI engine, hdmstream camera layer, farmer dashboard, admin panel, 7 schedulers, 19+ key pages, ESP32 IoT firmware with multiple sensor types, and comprehensive storage monitoring — represents a substantial original work of software development.
